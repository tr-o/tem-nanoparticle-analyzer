# Methods / 評価設計

## 教師あり領域認識

- 入力：グレースケールTEM画像と**人手またはシミュレータの正解二値マスク**。
- 各画素の学習特徴：正規化輝度、多尺度Gaussian、Gaussianとの差、LoG、局所勾配、背景との差、局所分散。
- 分類器：RandomForestClassifier（55 trees、max_depth 19）。画像ごとに粒子/背景を均衡サンプリング。
- 予測：画素ごとの粒子確率マップ。閾値を超えた領域から微小連結成分を除外。

## 粒子の分離

距離変換・h-maximaによるマーカー・Watershed。これは**教師なし後処理**です。密集と重なりを自動で正しく分離できる保証はありません。特に粒径分布の大粒径側に誤差が出ます。

## 計測と出力

- 円相当径 `sqrt(4*A/pi)`、最大Feret径（scikit-image実装）、円形度 `4*pi*A/P²`、長短軸比。
- 辺縁で切れる粒子は集計から除外。
- `particles.csv`、`overlay.png`、`overview.png`、`probability.png`、`mask.png`、`summary.json`。
- nm換算はユーザー指定の`nm_per_px`のみ。原画像のスケールバー自動認識は未実装。

## 評価

テスト画像でDice、IoUを評価。模擬データでは各粒子の生成中心との距離対応から中心Precision/Recallも計算（真の重なり粒子は2D輪郭から必ず分割可能とは限らない）。

**旧試作報告値：** Dice=0.913、IoU=0.839、中心Precision=0.989、Recall=0.652（4枚平均）。この値は同じ生成系での初期計算であり、一般的なTEM精度を主張しない。

## 実測データ利用時に必要な検証

1. 画像単位で訓練・テスト分割し、同じ視野のタイルのリークを禁止する。
2. 低コントラスト、支持膜の濃淡、単独、密集、凝集を包含。
3. 粒子ごとのprecision/recallとdiameter MAEを**人手の独立した輪郭/インスタンス注釈**で測る。
4. 測定不能な強い重なりは不確実として別扱いにする。
