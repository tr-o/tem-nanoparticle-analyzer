# 検証・採否の基準

[README](../README.md) / [実験履歴](EXPERIMENTS.md)

## 評価対象を区別する

- **人工TEM**：生成器による正解マスク。パイプライン確認用で実験TEMへの一般化保証なし。
- **実測TEM / SEM（EMPS）**：公式train/testの粒子IDマスクにより、粒子一つずつのIoUを評価。ただしTEM/SEM混合。
- **実DM3 HRTEM（ANTEMA）**：原画素と校正メタデータの読込みは確認。専門家インスタンスGTがないため真のF1・粒径誤差は未評価。
- **弱教師の公開Pt/Ag図**：自動または部分目視で生成した擬似ラベル。学習にも使った視野の改善は独立評価ではない。

## 指標

真の粒子ID `G_j` と予測ID `P_i` を**1対1に対応**させ、`IoU(P_i,G_j) ≥ 0.5` をTP、未対応予測をFP、未対応GTをFNとする。F1 = `2TP/(2TP+FP+FN)`。Precision = `TP/(TP+FP)`、Recall = `TP/(TP+FN)`。

**画素Diceは粒子単位F1ではありません。** 連結した塊でも画素Diceが良くなる場合があるため、接触分離を評価する場合は必ず粒子単位の指標を見る。

**粒径MAE**：IoU≥0.5で対応できた粒子のみ。見落とした粒子の径誤差は含まない。nmへ換算できるのは校正済みの元データのみ。

## 残された課題

小粒子の取りこぼし、支持膜ノイズの偽陽性、重なった粒子の過分割と過剰除外、暗/明の撮像差、高分解能の位相コントラスト。**未知の装置・撮影セッションで撮ったDM3に独立GTを付けるまで、製品としての精度保証はしません**。

## モデル採用原則

前処理・モデル・閾値・学習リストを固定してからtestを評価。test結果を見た後で改良した場合、新たな未使用testが必要。No-Goも保存。各レポートには元画像、GT、予測、採用/除外、測長の校正状態を残す。
