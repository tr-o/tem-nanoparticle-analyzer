## 1. 結論：何が進んだか

高密度Pt-1について、**保存済み図から復元した500×500 px画像**と前回の15本の木のポータブルモデルで再推論し、v5の候補数を再現した。画像SHA-256はv5の監査記録に一致。

| 再推論（v5と同条件） | 候補数 |
|---|---:|
| 孤立粒子として自動採用 | 115 |
| 接触分割・再分離として自動採用 | 90 |
| 要確認 | 783 |
| 除外 | 63 |
| **合計** | **1,051** |

**これは真の粒子数ではない**。スケールバーも短く、元データでの確定換算ではないため、この監査の直径はpx単位。元画像ではなく以前の論文風解析図から復元した画素である点に注意。

![既存のPt-1での採用・要確認・除外と解析結果](../v5/spotcheck_status.jpg)

今回の本質的な更新は、**これまでの36件と重ならない60候補を、6層から無作為に10件ずつ抽出**して、モデルの採否を隠したまま二人が独立に評価できるようにしたこと。単に高優先度だけを見ると評価が偏るため、**除外や低優先度の候補も必ず含む**。

## 4. レビュー仕様と品質保証

- **カテゴリーは5種**：`single` / `touching_separable` / `overlap` / `background` / `uncertain`。
- レビュー時に**元モデル採否、LoG優先度、既存判定を見せない**。
- **別々の2名による同意判定**が必要。不一致は`disagreement_adjudication_required`として保持し、別の仲裁者が判定する。
- `uncertain` は確定採用とは扱わない。外挿に必要な全層の判定が揃わなければ統計を確定しない。
- 画像ハッシュ・候補CSVハッシュ・選択キューのハッシュを照合。**別画像・別倍率にレビューを適用できないよう検証**。
- レビュー履歴はJSONL追記専用。元のモデル結果CSVを書き換えない。
- 合意が得られた実画像候補の切り出し画像を、**物体レベルの教師データ**として書き出せる。ただし**輪郭のピクセル正解マスクではない**。同じ視野由来の切り出しをtrain/testに混在させない。
- **二人の独立性や専門性をソフトウェアが保証できるわけではない**。識別子を付けた作業と専門家の管理が必要。

## 6. 未解決の問題と次の判定基準

現時点では、60候補について**専門家ラベル0件 / 60件**。したがって、v4/v5の過剰除外率・真のprecision・粒径誤差を新たに測定したわけではない。

必要なのは (i) 元の高解像度TEM画像を入手し、(ii) 2名が独立して同じ画像の候補を確認し、(iii) 合意できた候補のみで「採用の妥当性」と「要確認・除外の測定可能率」を層別推定すること。加えて、**検出候補にも挙がらなかった粒子**を調べる独立した位置アノテーションがなければ、真のrecallは計算できない。

実画像で判定が終われば、

1. 採用候補のうち背景だった割合（偽採用の監査）、
2. 要確認・除外候補のうち測定可能だった割合（過剰除外の監査）、
3. 採用輪郭による直径と独立手計測径との差、
4. 画像・撮影条件単位の一般化性能、

をそれぞれ区別して算出する。
